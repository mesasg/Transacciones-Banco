# Transacciones Banco

[![CI/CD Pipeline](https://github.com/mesasg/Transacciones-Banco/actions/workflows/build.yml/badge.svg)](https://github.com/mesasg/Transacciones-Banco/actions/workflows/build.yml)

Aplicación bancaria en Spring Boot para gestionar clientes y transferencias entre cuentas, desarrollada para el curso de Arquitectura de Software de la Universidad de Antioquia.

Aplicación desplegada: https://transacciones-banco.onrender.com
